| Action | Linux and Windows | macOS |
| --- | --- | --- |
| New tab | Ctrl+T | ⌘T |
| Close tab | Ctrl+W | ⌘W |
| Address bar | Ctrl+L | ⌘L |
| Reload | Ctrl+R, F5 | ⌘R |
| Back / forward | Alt+← / Alt+→ | ⌘[ / ⌘] |
| Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab | ⌃Tab / ⌃⇧Tab |

Middle-click a tab to close it. On Windows, Esc leaves fullscreen.

## The address bar

The address bar takes three kinds of input and works out which you meant:

- a full URL, such as `https://example.com/page`
- a bare host, such as `example.com` or `localhost:3000`
- anything else, which is searched with DuckDuckGo
